在原生 Windows 上用 Python 3.12 标准库实现离线隐私保留合规审计。输入是合成记录、版本化保留规则和对具体记录冻结删除的事件。每条记录用业务时间与入账时间两轴描述，冻结事件可撤销，迟到更新不能改变已提交的审计水位。报告比较两套规则在指定水位下的实际删除资格，按两个时间轴输出互不重叠的最小变化区块，并为每个区块附能独立复核的反例及优先级证据。等优先级相斥规则要单独报冲突。禁止逐日或按时间网格展开，用小域穷举逐格校验报告，并用长跨度的稀疏夹具核对边界与确定性。数据和结果均留在工作区，交付 CLI 和说明，统一用 `python -B -m unittest discover -s tests -v` 运行核心验收。
